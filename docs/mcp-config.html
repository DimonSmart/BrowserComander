Use this style of configuration when your MCP client expects a local executable.

{
  "mcpServers": {
    "browsercommander": {

    }
  }
}

Remote ChatGPT test access with Dev Tunnels

ChatGPT developer mode does not connect to localhost directly. BrowserCommander exposes MCP locally at http://localhost:5082/mcp, so for ChatGPT testing you need a public HTTPS tunnel that forwards to the same local server.

  1. Start BrowserCommanderServer.exe locally.
  2. Sign in to the Dev Tunnels CLI with devtunnel user login.
  3. Start a temporary public tunnel with devtunnel host -p 5082 --allow-anonymous.
  4. Copy the HTTPS forwarding URL shown by Dev Tunnels and append /mcp.
https://xxxxx.euw.devtunnels.ms/mcp
Use /mcp for BrowserCommander. This server currently exposes HTTP MCP at /mcp, not /mcp/sse.

ChatGPT app draft fields

Field Value
Name BrowserCommander
Description Inspect and control authorized tabs in a local Chromium browser through MCP.
MCP server URL https://<your-tunnel-host>/mcp
Authentication No Authentication when the tunnel was started with --allow-anonymous.

Keep the browser extension options page pointed at http://localhost:5082. The tunnel URL is only for the remote ChatGPT connection.

Security warning for anonymous tunnels

devtunnel host -p 5082 --allow-anonymous is useful for short-lived testing, but it makes the forwarded MCP endpoint publicly reachable.

  • Use this only for temporary testing sessions.
  • Do not leave the tunnel running after the test is finished.
  • Do not use anonymous tunneling for sensitive browsing sessions or confidential data.
  • Remember that BrowserCommander can perform write actions against already authorized tabs.

Official references: Connect from ChatGPT, ChatGPT developer mode, OpenAI Help Center, Dev Tunnels CLI reference, Dev Tunnels security.

Recommended order

  1. Extract the portable bundle.
  2. Load the unpacked extension and verify the extension options point to http://localhost:5082.
  3. Use the stdio bridge if your MCP client does not support HTTP MCP.
  4. Authorize the current tab before making tool calls.
