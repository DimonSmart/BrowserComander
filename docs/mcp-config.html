Client configuration

MCP config examples

The portable bundle includes the same examples under config-examples\. Replace placeholder paths with the folder where you extracted the bundle.

Stdio bridge example

Use this style of configuration when your MCP client expects a local executable.

{
  "mcpServers": {
    "browsercommander": {
      "command": "C:\\Tools\\BrowserCommander\\BrowserCommander.McpStdioBridge.exe"
    }
  }
}

Direct HTTP example

Use this when your MCP client supports HTTP MCP directly.

http://localhost:5082/mcp

Recommended order

  1. Extract the portable bundle.
  2. Load the unpacked extension and verify the extension options point to http://localhost:5082.
  3. Use the stdio bridge if your MCP client does not support HTTP MCP.
  4. Authorize the current tab before making tool calls.
