Privacy

BrowserCommander privacy summary

BrowserCommander is designed as a local-first tool. In the alpha release, the extension only connects to a local MCP server on a loopback address such as http://localhost:5082.

What data the product can handle

  • Authorized tab metadata such as title and URL.
  • Page content or automation results that the user or MCP client explicitly requests.
  • Console output, screenshots, or network metadata if the user invokes those tools.

What the alpha does not do

  • No built-in cloud telemetry or analytics.
  • No external BrowserCommander-hosted backend.
  • No automatic publication of browsing data to third-party services by default.

User control

  • The browser user explicitly chooses which tab may be automated.
  • The extension settings page shows and controls the local server address.
  • The user can revoke tab authorization at any time from the popup.
