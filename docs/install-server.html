Portable Windows bundle

Install the server and stdio bridge

Download browsercommander-windows-x64-portable-vX.Y.Z.zip from the latest GitHub Release and extract it to a writable folder such as C:\Tools\BrowserCommander.

Open latest release

Files in the bundle

  • BrowserCommanderServer.exe hosts the local HTTP MCP endpoint.
  • BrowserCommander.McpStdioBridge.exe exposes the same tools over stdio.
  • config-examples\ contains starter MCP client configuration snippets.

Startup options

Option A: start the server manually

BrowserCommanderServer.exe

The server should listen on http://localhost:5082.

Option B: let the stdio bridge auto-start the server

If BrowserCommander.McpStdioBridge.exe and BrowserCommanderServer.exe are in the same extracted folder, the bridge can auto-start the server when your MCP client launches the bridge.

Direct HTTP MCP endpoint

http://localhost:5082/mcp

If your client supports HTTP MCP directly, you do not need the stdio bridge.

Temporary remote access for ChatGPT

ChatGPT developer mode currently requires a remote MCP server URL. To test BrowserCommander from ChatGPT while the server still runs on your own machine, place a temporary HTTPS tunnel in front of http://localhost:5082. 

devtunnel user login
devtunnel host -p 5082 --allow-anonymous

Copy the tunnel URL shown by Dev Tunnels, append /mcp, and use that full URL in the ChatGPT app draft form. Detailed field mapping and security notes are on MCP config examples.
