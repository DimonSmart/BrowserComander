Support

How to get help

The public alpha is distributed through GitHub. The best way to report a problem or ask for a missing feature is to open an issue in the repository.

Open GitHub issues View repository

What to include in a bug report

  • Your browser and version.
  • Whether you are using Chrome or Edge.
  • The BrowserCommander release version.
  • The server address configured in the extension options page.
  • The exact failing command, tool call, or browser page.

Security note

This alpha is intentionally local-only. Do not expose the MCP server to public networks. If you discover a security-sensitive issue, avoid posting private browsing data in a public issue.
