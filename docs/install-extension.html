Chrome and Edge

Install the unpacked extension

The alpha release is distributed as an unpacked extension package. Download browsercommander-extension-unpacked-vX.Y.Z.zip from the latest GitHub Release and extract it first.

Open latest release

Chrome

  1. Open chrome://extensions.
  2. Turn on Developer mode.
  3. Select Load unpacked.
  4. Choose the extracted extension folder that contains manifest.json.
Official Chrome unpacked install flow: Load unpacked.

Edge

  1. Open edge://extensions.
  2. Turn on Developer mode.
  3. Select Load unpacked.
  4. Choose the extracted extension folder that contains manifest.json.

After installation

  1. Open the extension Options page and verify the local server address. The default is http://localhost:5082.
  2. Open the popup on the tab you want to automate.
  3. Click Authorize Current Tab.
